# Hy4-flash lane: measurements up to 2026-11-24

All on one DGX Spark with the pack described in the [lane README](../README.md#the-pack) and the settings of
[scripts/start.sh](../scripts/start.sh), unless a line says otherwise. Decode tok/s is completion tokens over decode
seconds from the server's own counters (prefill excluded) unless it says "end to end".

## Decode

| What | Result | Date |
|---|---|---|
| One stream, eight real prompts one after another (2 Korean ShareGPT, 2 code generation, 1 Korean Alpaca, 1 English OASST2, 1 code edit, 1 Korean code; public datasets), server sampling (temperature 0.9, top-k 10), a fixed seed per request, up to 1,200 tokens | 49.1 tok/s; 2.36 tokens a round; 0.68 of the drafts accepted | 2026-11-24 |
| Real chat use after the drafter update: 26 requests, 41,497 tokens | about 55 tok/s; 3.12 tokens a round | 2026-11-24 |
| Greedy, a Korean summary of a 4k-token prompt, 96 tokens | 54.7 tok/s with drafts, 33.2 without | 2026-11-24 |
| Four streams at a time, 16 real prompts | 78.2 tok/s in total | 2026-11-24 |
| sgbench, end to end with time to first token, thinking on, token-weighted | 51.4 / 64.2 / 85.7 tok/s at 1 / 2 / 4 streams | 2026-11-23 |

Where a round's time goes (greedy, 4k context, 2026-11-24): the verify forward takes 30.6 ms for one row and
36.9 / 42.6 / 47.3 / 52.6 / 57.4 ms for 2-6 rows (each extra row adds 5-6 ms, mostly routed experts that the earlier rows
did not use: a row brings about 8 new experts a layer); the drafter and the host take about 3.8 ms more. Most of a round
is weight reads at close to the memory bandwidth, so the remaining levers are fewer bytes a token or more accepted drafts.
